# 🚜 Bulldozer Price Prediction — Machine Learning Project

## Project Overview
This project uses machine learning to predict bulldozer sale prices based on equipment characteristics and historical sales data.

The goal is to build, evaluate, and interpret a regression model using Python and Scikit-learn.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Project Workflow
1. Load and explore the bulldozer sales dataset.
2. Clean and preprocess the data.
3. Prepare features for machine learning.
4. Train a regression model.
5. Evaluate model performance.
6. Generate bulldozer price predictions.
7. Analyze feature importance.
8. Export prediction results to CSV.

## Model Results
- **Final prediction MAE:** $6,835.91
- **Most important feature:** ProductSize
- **ProductSize feature importance:** 28.19%
- **Combined importance of top five features:** 67.29%

The Mean Absolute Error (MAE) measures the average absolute difference between predicted and actual bulldozer prices.
